# Srishti's Luxe Canvas

PRD — Premium Website for Srishti’s Salon & Academy

Objective

Create a premium modern website for a nail salon + beauty academy that feels luxurious, cinematic, and smooth while still remaining minimal and elegant.

The website should:

showcase nail artistry professionally

feel like a luxury beauty brand website

generate salon bookings

generate academy inquiries

stand out from generic salon templates

The website should have:

ONE strong cinematic intro interaction

clean premium sections after that

The website should NOT feel:

overly experimental

cluttered

overly feminine template-style

animation overloaded

Overall Design Direction

Visual Style

luxury cosmetic brand inspired

editorial/fashion aesthetic

soft premium lighting

smooth motion

minimal layouts

elegant typography

Think:

Dior beauty campaigns

luxury cosmetic landing pages

Apple-style smooth interactions

Primary:

Accent:

deep burgundy

Avoid:

excessive colors

HERO SECTION (Main Highlight)

Core Concept

The intro interaction should revolve around a luxury nail polish bottle and flowing polish animation.

The hero should feel cinematic and interactive without becoming overly complex.

HERO LAYOUT

Left Side

Content area.

Includes:

logo

heading

small supporting text

CTA buttons

Example:

Heading:

Art You Wear.

Subtext:
Premium nail artistry, beauty services, and professional academy training.

Buttons:

Book Appointment

Explore Academy

Right Side

Interactive visual area.

Contains:

isolated luxury nail polish bottle

glossy polish drip assets

flowing paint stroke elements

soft cinematic lighting

Background:

soft beige luxury texture

subtle grain

minimal vignette

HERO ANIMATION FLOW

Initial State

Bottle floating naturally.

Subtle idle animation:

slow movement

slight rotation

soft shadow

The scene should feel calm and premium.

SCROLL INTERACTION

Stage 1

As user scrolls:

bottle slowly tilts downward

Movement should feel:

smooth

realistic

heavy

elegant

Stage 2

Glossy polish begins forming at bottle opening.

Small liquid blob appears.

Stage 3

The polish drip stretches downward with scroll progress.

Use:

elongated drip PNG assets

smooth scaling/stretch animation

The drip itself becomes the transition element.

Stage 4

As the polish stretches:

hero text reveals

CTA buttons fade in

background visuals softly appear

Reveal should happen through:

masks

soft fades

blur-to-clear transitions

NOT harsh popups.

Stage 5

The stretched polish transitions into:

curved paint stroke
or

subtle divider line

This paint element continues slightly into the next section as a branding element.

IMPORTANT HERO RULE

The cinematic interaction should finish within:

first 100vh scroll only.

After that:
website transitions into normal smooth scrolling.

The intro is the “hatke” moment.
The rest of the site should remain elegant and usable.
